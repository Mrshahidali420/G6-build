Official Rockstar press images go here, named after the entity slug.

Example: public/img/entities/lucia-caminos.jpg

Accepted: .jpg .jpeg .png .webp .avif
Any entry with a file here shows the photo instead of its terrazzo plate.

credits.json in this folder maps a slug to the credit line, for example:
  { "lucia-caminos": "Rockstar Games, Grand Theft Auto VI trailer 1" }
Add the credit line at the same time as the image. No image ships uncredited.
