## The short answer

**Rockstar has not published a file size for GTA 6.** No install size figure
exists yet from Rockstar, Sony or Microsoft. Any number you see quoted online
right now is a guess, not a fact.

## Why there is no number yet

Game file sizes are usually confirmed close to release, once the developer has
finished packaging the game for each console's store. Rockstar has confirmed
the release date, the price, and the editions for GTA 6, but the store listings
on PlayStation and Xbox do not yet show a download size field filled in.

This is normal. Large open-world games often have their file size figure added
to the store page in the weeks before launch, not months ahead. GTA 6 has not
reached that stage of its rollout yet.

## Where the real number will show up first

When Rockstar or the platform holders do publish a file size, it will most
likely appear in one of these places first.

| Source | What to watch for |
| --- | --- |
| PlayStation Store product page | A "size" or "file size" field once it is filled in |
| Xbox Store product page | A "size" field in the game's details section |
| Rockstar Newswire | An official post mentioning storage requirements |

Checking those pages directly is more reliable than trusting a number shared on
social media or a forum.

## Why preloading is the moment to watch

Rockstar has confirmed that preloading starts on **12 November 2026**, one week
before the 19 November 2026 release date. Preloading only works if your console
knows how many gigabytes to download and store, so the file size almost has to
be locked in and visible by that point, even if Rockstar never puts out a
separate announcement about it.

That makes the run-up to 12 November 2026 the most sensible window to expect
the number to surface, whether through an official statement or simply by
appearing on the store listing itself.

## What affects a game's file size in general

No number is confirmed for GTA 6, but it helps to understand what usually makes
one open-world console game larger than another.

- **Texture quality.** Higher-resolution textures for buildings, characters and
  vehicles take up more space.
- **Audio.** A big city with full voice acting, radio stations and ambient
  sound adds gigabytes fast.
- **Compression choices.** Some games trade a larger download for faster load
  times, others compress harder and load a bit slower.
- **Day-one patches.** Many big releases ship with a patch that downloads
  alongside or right after the base install, which can add to what you actually
  need to clear.

None of this tells you what GTA 6 will need. It only explains why big
open-world games vary so much from one another.

## Sensible advice for now

You do not need a confirmed number to start getting ready.

1. **Check your current free space** on your PS5 or Xbox Series X|S in the
   storage settings menu.
2. **Uninstall games you have finished** or are not actively playing. Most
   consoles let you reinstall later without losing save data tied to the cloud.
3. **Leave headroom**, not just enough for the base game. A day-one patch and
   any post-launch updates will need extra room too.
4. **Watch the store listing**, not rumour sites, once preloading opens in
   November 2026.

## What is still not known

- No file size or install size has been published by Rockstar, Sony or
  Microsoft.
- No confirmation of whether physical disc buyers will need the same download
  size as digital buyers. Physical copies ship with a download code rather than
  the full game on disc, which usually means a similar download either way, but
  Rockstar has not confirmed the exact figure for either format.
- No word on day-one patch size.

This page will be updated the moment a real number appears on an official
store listing or from Rockstar directly.
